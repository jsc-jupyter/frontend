# Jupyterhub React Base Frontend

This repository contains the currently still WIP implementation of the Jupyterhub Base Frontend in React.

### Build Commands

- `dev`: Starts dev server, currently not usable
- `build`: Bundles the application
- `build:watch`: Bundles the application and watches for changes
- `prettier`: Runs prettier
- `lint`: Runs eslint
- `lint:fix`: Runs eslint and fixes autofixable issues
