# Jupyterhub React Base Frontend

This repository contains the currently still **work in progress** implementation of the Jupyterhub Base Frontend in React.

In production the following repository https://github.com/jsc-jupyter/base-frontend/tree/production is being used.


### Build Commands

- `dev`: Starts dev server, currently not usable
- `build`: Bundles the application
- `build:watch`: Bundles the application and watches for changes
- `prettier`: Runs prettier
- `lint`: Runs eslint
- `lint:fix`: Runs eslint and fixes autofixable issues
